# Мой день
Личный Telegram Mini App. Python 3.12, SQLite. Откройте index.html в браузере с поддержкой localStorage для локального просмотра. Локальные записи отделены от Telegram.
## Railway
Подключите репозиторий к сервису diary, оставьте Dockerfile в корне, подключите том к /data. Используйте один экземпляр сервиса. Домен должен быть включён (RAILWAY_PUBLIC_DOMAIN). В Variables добавьте BOT_TOKEN из @BotFather. После деплоя отправьте боту /id, запишите показанное число в OWNER_ID и примените изменения. Команда /start откроет дневник только владельцу. Время дневника — московское. КБЖУ вводятся на порцию вручную.
